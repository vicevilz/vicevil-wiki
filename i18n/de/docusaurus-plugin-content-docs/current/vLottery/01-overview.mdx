# Funktionen und Voraussetzungen

Jedes Los hat dasselbe Gewicht. Mehr Lose erhöhen die Gewinnchance proportional, garantieren aber keinen Gewinn.

Bestätigte Funktionen: Käufe über Vault, persistenter Pot, anteiliger Jackpot und Rollover, automatische/manuelle/Wiederherstellungs-Ziehungen, Offline-Gewinne, Teilnahme-Buffs, Rangliste, sechs Sprachen, DeluxeMenus, PlaceholderAPI, Discord und öffentliche Bukkit-Events.

| Komponente | Voraussetzung |
|---|---|
| Server | Paper API 1.21 |
| Java | Java 21 |
| Plugins | LuckPerms, Vault, PlaceholderAPI, DeluxeMenus |
| Wirtschaft | In Vault registrierter Economy-Provider |
| Mitgeliefertes Menü | Formatter, Math, Utils und vTime für alle zusammengesetzten Formate |

vLottery 1.0.0 wurde mit Paper 1.21 und 1.21.11 validiert. Für nicht getestete Plattformen wird keine vollständige Kompatibilität behauptet.
