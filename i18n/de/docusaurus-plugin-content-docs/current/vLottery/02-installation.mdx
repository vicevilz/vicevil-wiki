# Installation und Updates

1. Server stoppen.
2. LuckPerms, Vault, Economy-Provider, PlaceholderAPI und DeluxeMenus installieren.
3. Für das Menü Formatter, Math, Utils und vTime installieren.
4. `vLottery-Paper-1.0.0.jar` nach `plugins/` kopieren.
5. Server starten und Economy-Erkennung prüfen.
6. `plugins/vLottery/config.yml` prüfen und `/vlottery status` testen.

Vor einem Update `plugins/vLottery/`, `plugins/DeluxeMenus/config.yml` und `plugins/DeluxeMenus/gui_menus/vLottery/` bei gestopptem Server sichern. Nur die JAR ersetzen und anschließend Status, Menü und einen kontrollierten Kauf testen.

Vorhandene Menüdateien werden nicht automatisch überschrieben. Anpassungen behalten und neue Vorgaben manuell vergleichen.
