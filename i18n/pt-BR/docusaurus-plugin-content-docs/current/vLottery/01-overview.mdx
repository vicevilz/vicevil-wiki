# Recursos e requisitos

Cada bilhete tem o mesmo peso. Mais bilhetes aumentam proporcionalmente a chance, mas nunca garantem a vitória.

Recursos confirmados: compras via Vault, pote persistente, jackpot parcial e rollover, sorteios automáticos/manuais/de recuperação, prêmios offline, buffs de participação, ranking, seis idiomas, DeluxeMenus, PlaceholderAPI, Discord e eventos Bukkit públicos.

| Componente | Requisito |
|---|---|
| Servidor | Paper API 1.21 |
| Java | Java 21 |
| Plugins | LuckPerms, Vault, PlaceholderAPI e DeluxeMenus |
| Economia | Provedor registrado no Vault |
| Menu incluído | Formatter, Math, Utils e vTime para todos os formatos compostos |

vLottery 1.0.0 foi validado no Paper 1.21 e 1.21.11. Não há afirmação de compatibilidade completa com plataformas não testadas.
