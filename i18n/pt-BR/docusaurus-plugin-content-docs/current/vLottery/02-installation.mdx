# Instalação e atualizações

1. Pare o servidor.
2. Instale LuckPerms, Vault, um provedor de economia, PlaceholderAPI e DeluxeMenus.
3. Para o menu incluído, instale Formatter, Math, Utils e vTime.
4. Copie `vLottery-Paper-1.0.0.jar` para `plugins/`.
5. Inicie e confirme a detecção da economia.
6. Revise `plugins/vLottery/config.yml` e teste `/vlottery status`.

Antes de atualizar, com o servidor parado, faça backup de `plugins/vLottery/`, `plugins/DeluxeMenus/config.yml` e `plugins/DeluxeMenus/gui_menus/vLottery/`. Substitua apenas o JAR e teste status, menu e uma compra controlada.

Menus existentes não são sobrescritos automaticamente. Preserve personalizações e compare novos padrões manualmente.
