# Características y requisitos

Cada boleto tiene el mismo peso. Un jugador con más boletos aumenta proporcionalmente su probabilidad, pero no garantiza ganar.

Funciones: compras mediante Vault, bote persistente, jackpot parcial, rollover, sorteos automáticos/manuales/de recuperación, premios offline, buffs de participación, clasificación, seis idiomas, DeluxeMenus, PlaceholderAPI, Discord y eventos Bukkit públicos.

## Requisitos

| Componente | Requisito |
|---|---|
| Servidor | Paper API 1.21 |
| Java | Java 21 |
| Plugins | LuckPerms, Vault, PlaceholderAPI y DeluxeMenus |
| Economía | Proveedor compatible registrado en Vault |
| Menú incluido | Formatter, Math, Utils y vTime para todos sus formatos compuestos |

vLottery 1.0.0 fue validado en Paper 1.21 y 1.21.11. No se afirma compatibilidad completa con plataformas no probadas.
