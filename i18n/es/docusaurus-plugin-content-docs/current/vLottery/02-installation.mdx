# Instalación y actualización

1. Detén el servidor.
2. Instala LuckPerms, Vault, un proveedor económico, PlaceholderAPI y DeluxeMenus.
3. Para el menú incluido, instala Formatter, Math, Utils y vTime.
4. Copia `vLottery-Paper-1.0.0.jar` a `plugins/`.
5. Arranca y confirma que se detecta el proveedor económico.
6. Revisa `plugins/vLottery/config.yml` y prueba `/vlottery status`.

## Actualizar o reinstalar

Detén el servidor y respalda `plugins/vLottery/`, `plugins/DeluxeMenus/config.yml` y `plugins/DeluxeMenus/gui_menus/vLottery/`. Sustituye solo el JAR, arranca y comprueba estado, menú y una compra controlada.

Los archivos de menú ya existentes no se sobrescriben automáticamente. Conserva tus personalizaciones y compara manualmente los cambios de una versión nueva.
