# Funkcje i wymagania

Każdy los ma taką samą wagę. Więcej losów proporcjonalnie zwiększa szansę, lecz nie gwarantuje wygranej.

Potwierdzone funkcje: zakupy przez Vault, trwała pula, częściowy jackpot i rollover, losowania automatyczne/ręczne/naprawcze, nagrody offline, buffy uczestnictwa, ranking, sześć języków, DeluxeMenus, PlaceholderAPI, Discord oraz publiczne zdarzenia Bukkit.

| Składnik | Wymaganie |
|---|---|
| Serwer | Paper API 1.21 |
| Java | Java 21 |
| Pluginy | LuckPerms, Vault, PlaceholderAPI, DeluxeMenus |
| Ekonomia | Provider zarejestrowany w Vault |
| Dołączone menu | Formatter, Math, Utils i vTime dla wszystkich złożonych formatów |

vLottery 1.0.0 zweryfikowano na Paper 1.21 i 1.21.11. Nie deklaruje się pełnej zgodności z nietestowanymi platformami.
