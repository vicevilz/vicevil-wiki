# Instalacja i aktualizacje

1. Zatrzymaj serwer.
2. Zainstaluj LuckPerms, Vault, provider ekonomii, PlaceholderAPI i DeluxeMenus.
3. Dla dołączonego menu zainstaluj Formatter, Math, Utils i vTime.
4. Skopiuj `vLottery-Paper-1.0.0.jar` do `plugins/`.
5. Uruchom serwer i sprawdź wykrycie ekonomii.
6. Przejrzyj `plugins/vLottery/config.yml` i przetestuj `/vlottery status`.

Przed aktualizacją, przy wyłączonym serwerze, wykonaj kopię `plugins/vLottery/`, `plugins/DeluxeMenus/config.yml` i `plugins/DeluxeMenus/gui_menus/vLottery/`. Wymień tylko JAR, następnie sprawdź status, menu i kontrolowany zakup.

Istniejące menu nie są automatycznie nadpisywane. Zachowaj modyfikacje i porównaj nowe domyślne pliki ręcznie.
