# Fonctions et prérequis

Chaque ticket possède le même poids. Davantage de tickets augmente proportionnellement les chances, sans garantir la victoire.

Fonctions confirmées : achats Vault, cagnotte persistante, jackpot partiel et rollover, tirages automatiques/manuels/de récupération, gains hors ligne, buffs de participation, classement, six langues, DeluxeMenus, PlaceholderAPI, Discord et événements Bukkit publics.

| Composant | Prérequis |
|---|---|
| Serveur | Paper API 1.21 |
| Java | Java 21 |
| Plugins | LuckPerms, Vault, PlaceholderAPI, DeluxeMenus |
| Économie | Fournisseur enregistré dans Vault |
| Menu fourni | Formatter, Math, Utils et vTime pour tous les formats composés |

vLottery 1.0.0 a été validé sur Paper 1.21 et 1.21.11. Aucune compatibilité complète n'est affirmée pour les plateformes non testées.
