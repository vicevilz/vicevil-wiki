# Features and requirements

Every ticket has equal weight. More tickets proportionally increase a player's odds, but never guarantee a win.

Confirmed features include Vault purchases, a persistent pot, partial jackpot and rollover, automatic/manual/recovery draws, offline prizes, participation buffs, leaderboard, six locales, DeluxeMenus, PlaceholderAPI, Discord and public Bukkit events.

| Component | Requirement |
|---|---|
| Server | Paper API 1.21 |
| Java | Java 21 |
| Plugins | LuckPerms, Vault, PlaceholderAPI and DeluxeMenus |
| Economy | A Vault-registered economy provider |
| Bundled menu | Formatter, Math, Utils and vTime for every composite format |

vLottery 1.0.0 was validated on Paper 1.21 and 1.21.11. Compatibility is not claimed for untested platforms.
