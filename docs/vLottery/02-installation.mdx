# Installation and updates

1. Stop the server.
2. Install LuckPerms, Vault, an economy provider, PlaceholderAPI and DeluxeMenus.
3. For the bundled menu, install Formatter, Math, Utils and vTime.
4. Copy `vLottery-Paper-1.0.0.jar` into `plugins/`.
5. Start the server and confirm that an economy provider is detected.
6. Review `plugins/vLottery/config.yml` and test `/vlottery status`.

Before updating, stop the server and back up `plugins/vLottery/`, `plugins/DeluxeMenus/config.yml` and `plugins/DeluxeMenus/gui_menus/vLottery/`. Replace only the JAR, then test status, menu opening and a controlled purchase.

Existing menu files are not overwritten automatically. Preserve customizations and compare new defaults manually.
