# Sorteos y programación

## Formato de `draw.cron`

No es cron UNIX. Es una lista semanal:

```yaml
draw:
  cron: "wed 18:00, sun 12:00"
```

Días válidos: `mon`, `tue`, `wed`, `thu`, `fri`, `sat`, `sun`. La hora exige dos dígitos y formato `HH:mm`; `2:46` es inválido y `02:46` es válido.

Para desactivar sorteos automáticos:

```yaml
draw:
  cron: "0"
```

## Zona horaria

`draw.timezone` acepta un identificador IANA, por ejemplo `Europe/Madrid`. El cálculo utiliza esa zona y resuelve los cambios horarios con las reglas de Java.

## Recordatorios

Se envía como máximo uno por ronda cuando `reminder.minutes` es mayor que cero y `broadcast.reminders` está activo.

## Recuperación tras apagado

Si al arrancar existe una fecha persistida ya vencida, se ejecuta un único sorteo con trigger `RECOVERY` y después se calcula la siguiente fecha. No se reproducen todos los sorteos históricos perdidos.

## Sorteo cancelado por otro plugin

Si `LotteryPreDrawEvent` se cancela, el bote, boletos y ronda permanecen activos. El siguiente sorteo se programará normalmente en el caso del planificador automático.
