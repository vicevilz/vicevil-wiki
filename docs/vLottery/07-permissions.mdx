# Permisos

| Permiso | Predeterminado | Función |
|---|---|---|
| `vlottery.use` | `true` | Usar el comando raíz |
| `vlottery.buy` | `true` | Comprar boletos |
| `vlottery.leaderboard` | `true` | Consultar clasificación |
| `vlottery.status` | `true` | Consultar estado |
| `vlottery.notify` | `true` | Recibir anuncios y títulos del plugin |
| `vlottery.admin` | `op` | Estado administrativo e incluye los tres permisos siguientes |
| `vlottery.admin.raffle` | `op` | Sorteo manual |
| `vlottery.admin.reload` | `op` | Recarga segura |
| `vlottery.admin.donate` | `op` | Donaciones administrativas |

Ejemplo con LuckPerms:

```text
/lp group default permission set vlottery.use true
/lp group default permission set vlottery.buy true
/lp group admin permission set vlottery.admin true
```

Quitar `vlottery.notify` evita anuncios de chat y títulos dirigidos por vLottery, pero no cambia la participación del jugador.
