# API y eventos

Paquete: `net.vicevil.vlottery.api.event`. Los eventos se escuchan mediante el sistema habitual de Bukkit/Paper.

| Evento | Momento | Cancelable | Datos principales |
|---|---|---:|---|
| `LotteryTicketPurchaseEvent` | Antes de cobrar | Sí | ronda, jugador, cantidad, precio unitario y total |
| `LotteryPreDrawEvent` | Antes de comprobar mínimo/seleccionar | Sí | trigger y snapshot |
| `LotteryDrawEvent` | Tras persistir una ronda ganadora | No | trigger, snapshot, ganador y premio |
| `LotteryWinEvent` | Tras persistir la obligación de premio | No | ronda, ganador, premio e ID de premio |
| `LotteryPotChangeEvent` | Compra, donación o pago | No | bote anterior/nuevo, delta, causa y actor |
| `LotteryRoundCancelEvent` | Ronda cerrada sin mínimo | No | trigger, snapshot y motivo |

## Enumeraciones

- `DrawTrigger`: `AUTOMATIC`, `MANUAL`, `RECOVERY`.
- `PotChangeCause`: `TICKET_PURCHASE`, `DONATION`, `PRIVATE_DONATION`, `PRIZE_PAYOUT`.
- `RoundCancelReason`: `MINIMUM_PLAYERS`.

`LotteryRoundSnapshot` contiene `roundId`, `pot`, `jackpot`, mapa inmutable UUID→boletos, participantes y boletos totales.

## Ejemplo

```java
@EventHandler
public void onPurchase(LotteryTicketPurchaseEvent event) {
    if (event.getTicketCount() > 500) {
        event.setCancelled(true);
    }
}
```

Cancelar una compra evita el cobro. Cancelar `LotteryPreDrawEvent` deja la ronda activa sin alterar bote ni boletos.
