# Preguntas frecuentes y limitaciones

## ¿Más boletos garantizan ganar?

No. Aumentan la probabilidad proporcional, pero no garantizan el resultado.

## ¿El jackpot es todo el bote?

Solo si `draw.portion` vale `1`. Con `0.88`, se paga hasta el 88 % redondeado hacia abajo y el resto continúa acumulado.

## ¿Un sorteo manual ignora el mínimo?

No. `draw.min-players` también se aplica a `/vlottery raffle`.

## ¿Se pierden boletos si faltan participantes?

No. La ronda se cierra sin ganador y conserva bote y boletos para el siguiente intento.

## ¿Puedo usar únicamente sorteos manuales?

Sí. Configura `draw.cron: "0"`.

## ¿Qué versión es la actual?

La fuente y el paquete correctivo más recientes analizados declaran `0.1.1`, producido después del artefacto `1.0.0`. Esta numeración descendente puede confundir gestores automáticos; identifica el JAR por su nombre y origen.

## Limitaciones verificadas

- Vault no proporciona una clave idempotente universal. El plugin persiste y concilia el premio, pero no puede prometer una garantía absoluta si el proceso termina exactamente entre el depósito externo y su confirmación local.
- [No verificado] El webhook real de Discord no se probó; el backend se validó contra un servidor HTTP local.
- [No verificado] No se realizó una revisión visual final mediante captura de un cliente gráfico.
- Formatter, Math y Utils no fueron comprobados funcionalmente en el servidor aislado de validación.
- Solo se afirma compatibilidad para los entornos enumerados en [Características y compatibilidad](01-overview.mdx).
