# Discord y notificaciones

Discord solo está activo cuando coinciden estas tres condiciones:

```text
messaging.enabled = true
messaging.backends.discord.enabled = true
webhook no vacío
```

Se envían embeds para recordatorios, ganadores, rondas sin mínimo, donaciones públicas e hitos, según sus interruptores. Las donaciones `private` nunca producen mensaje de Discord.

## Cola y límites

Los mensajes se procesan en una cola FIFO limitada. El token bucket controla el ritmo y los reintentos cubren respuestas temporales como rate limits o errores del servidor remoto. Si se llena la cola o se agotan los intentos, se registra un aviso.

## Seguridad

- No publiques el webhook ni lo incluyas en capturas.
- Respalda `config.yml` antes de cambiarlo.
- Regenera el webhook en Discord si se filtra.
- Una recarga crea una configuración de mensajería nueva y cierra la anterior solo si toda la recarga resulta válida.
