# Instalación de vStaff

:::caution Pendiente de verificar
Añade aquí la versión del servidor, la versión de Java, las dependencias y el procedimiento de instalación confirmados.
:::

1. Descarga la versión compatible desde la fuente oficial.
2. Detén el servidor antes de instalar o sustituir el archivo del plugin.
3. Coloca el archivo `.jar` en `plugins/`.
4. Inicia el servidor y revisa la consola.
